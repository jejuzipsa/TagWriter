TagWriter cumulative patch notes

0.0.0.4
- Audited the 0.0.0.3 GitHub Actions artifact: the build succeeded and the artifact contained a 161,676,298-byte unsigned single-file Windows executable plus PDB.
- Changed Windows packaging from self-contained single-file to ordinary self-contained folder deployment. This keeps TagWriter portable while avoiding the unusually large bundled EXE that can attract reputation/SmartScreen scrutiny and makes runtime files easier to inspect.
- Artifact remains a single GitHub download ZIP; there is no ZIP-inside-ZIP.
- Kept startup crash logging introduced in 0.0.0.3.
- Bumped application/package version to 0.0.0.4.

0.0.0.3
- Fixed a startup regression in 0.0.0.2 by removing the newly embedded/window-bound icon path from startup resources.
- Added a startup/unhandled-exception crash log (TagWriter_crash.log) and visible error dialog for future launch failures.
- Bumped package version to 0.0.0.3.

0.0.0.2
- Reworked the main desktop layout after reviewing the supplied novelWriter package.
- Kept the dedicated writing-app structure while giving TagWriter its own activity rail, centered writing canvas, context inspector and visual hierarchy.
- Improved dark-theme contrast, typography, panel separation and editor readability.
- Added a compact dark/light switch in the upper-right corner and a light palette.
- Refined the status bar and editor header.
- Removed nested ZIP packaging from GitHub Actions artifacts.
- Bumped application/package version to 0.0.0.2.

0.0.0.1
- Initial .NET 8 WPF prototype.
- Added chapter/scene structure, setting cards, aliases, occurrence lookup, basic mind-map data, ideas and single-JSON project storage.
