0.0.5.8
- Added a global typewriter-sound control to the empty top-right toolbar area: [타자기] switch, volume icon, and volume slider.
- Typewriter sound works in both normal manuscript mode and manuscript-paper mode.
- Added per-key-position sound mapping. Physical keyboard regions use eight slightly different key sounds, so Korean IME keys such as D(ㅇ) and P(ㅔ) do not sound identical.
- Space, Backspace/Delete, and Enter use separate mechanical sounds; Enter includes a carriage-return/bell style effect.
- Added a small playback pool so rapid typing can overlap instead of constantly cutting off the previous keystroke.
- Typewriter enabled state and volume are saved in the project JSON settings.
- Added a locally generated offline typewriter sound set. TagWriter creates its key/space/backspace/carriage-return WAVs on first use, so there is no network or external audio-file dependency.
- Bumped version to 0.0.5.8.
