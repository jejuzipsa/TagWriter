TagWriter cumulative patch notes

0.0.1.1
- Fixed the project-tree selected item using the native white WPF highlight; tree selection now follows TagWriter's themed selection color.
- Removed the inactive bottom-left gear/settings button until an actual settings screen exists.
- Added collapsible PROJECT and CONTEXT side panels with < / > controls.
- Collapsed panels retain only P or C plus the expand control; their content and splitter are hidden.
- Added minimum expanded widths: 210 px for PROJECT and 260 px for CONTEXT, while preserving the user's last wider size when collapsing and reopening.
- Bumped version to 0.0.1.1.

0.0.1.0
- Added BUILD.bat for the local GitHub Desktop workflow: Pull, double-click BUILD.bat, and the latest TagWriter is built into publish and launched automatically.
- Corrected the patch version sequence: the tenth incremental build is now 0.0.1.0 instead of 0.0.0.10.
- Rebuilt the same chapter-title feature under the corrected version number to produce a fresh GitHub Actions artifact.

0.0.0.10
- Double-clicking a chapter in the left project tree now opens a chapter-title editor.
- Chapter titles remain freely editable for named/atmospheric chapter headings; scene titles remain internal and are not exposed for renaming.
- New chapters still receive automatic sequential names. Korean-style projects create 2장, 3장, etc.; projects whose first chapter uses Chapter N create Chapter 2, Chapter 3, etc.
- Bumped version to 0.0.0.10.

0.0.0.9
- Replaced the fixed left-tree manuscript label "원고" with the current novel/project title.
- Double-clicking that novel title in the left project tree now opens the title editor.
- The existing File > 소설 제목 변경 command and tree double-click use the same rename flow.
- Bumped version to 0.0.0.9.

0.0.0.8
- Replaced the native WPF context-tab header rendering with a custom template so selected tabs use the intended subtle dark selection color instead of white.
- Added visible selected-state feedback to the left Project, Manuscript and Mind Map activity buttons.
- Changed editor breadcrumb separators from long dashes to compact vertical bars: title | chapter | scene.
- Added File > 소설 제목 변경... with a title-edit dialog; changes immediately update the window title, top project title and editor breadcrumb.
- Bumped version to 0.0.0.8.

0.0.0.7
- Fixed startup crash caused by MainWindow XAML trying to load Assets/TagWriter.ico as a WPF packaged resource even though the ICO is used as the executable ApplicationIcon.
- Removed the Window Icon XAML reference while retaining the executable icon setting.
- Bumped version to 0.0.0.7.

0.0.0.6
- Active context tabs now use a subtly darker theme color instead of the native white selected state.
- Wired the left Project and Manuscript activity buttons; Manuscript restores and focuses the current scene.
- Restored the existing TagWriter ICO to the window and executable now that folder deployment is stable.
- Editor heading now shows project title — chapter title — scene title.
- Bumped version to 0.0.0.6.

0.0.0.5
- Fixed the empty manuscript editor collapsing to zero height inside the ScrollViewer; the editor now fills the writing pane and accepts focus/clicks across the manuscript area.
- Added explicit dark/light styling for context tabs, including a clearly visible selected-tab state and hover state.
- Added an explicit theme-toggle template so its label, border and background remain visible in dark mode.
- Applied Windows DWM immersive dark title-bar mode so the native window title area follows TagWriter dark mode.
- Restored the saved project theme on startup instead of always forcing dark mode.
- Updated the in-app version label to 0.0.0.5.

0.0.0.4
- Audited the 0.0.0.3 GitHub Actions artifact: the build succeeded and the artifact contained a 161,676,298-byte unsigned single-file Windows executable plus PDB.
- Changed Windows packaging from self-contained single-file to ordinary self-contained folder deployment. This keeps TagWriter portable while avoiding the unusually large bundled EXE that can attract reputation/SmartScreen scrutiny and makes runtime files easier to inspect.
- Artifact remains a single GitHub download ZIP; there is no ZIP-inside-ZIP.
- Kept startup crash logging introduced in 0.0.0.3.
- Bumped application/package version to 0.0.0.4.

0.0.0.3
- Fixed a startup regression in 0.0.0.2 by removing the newly embedded/window-bound icon path from startup resources.
- Added a startup/unhandled-exception crash log (TagWriter_crash.log) and visible error dialog for future launch failures.
- Bumped package version to 0.0.0.3.

0.0.0.2
- Reworked the main desktop layout after reviewing the supplied novelWriter package.
- Kept the dedicated writing-app structure while giving TagWriter its own activity rail, centered writing canvas, context inspector and visual hierarchy.
- Improved dark-theme contrast, typography, panel separation and editor readability.
- Added a compact dark/light switch in the upper-right corner and a light palette.
- Refined the status bar and editor header.
- Removed nested ZIP packaging from GitHub Actions artifacts.
- Bumped application/package version to 0.0.0.2.

0.0.0.1
- Initial .NET 8 WPF prototype.
- Added chapter/scene structure, setting cards, aliases, occurrence lookup, basic mind-map data, ideas and single-JSON project storage.
